# ADESA carousel assets

Official logos are unchanged originals from `adesa_carousel_images_and_logos.zip`. `adesa_hq_emblem.webp` is a lossless crop of the official HQ house mark for small navigation contexts.

The active Media background is the latest user-supplied event photograph (WhatsApp Image 2026-11-11 at 10.22.13.jpeg), retained unchanged as carousel/media-event-41eb19f100-original.jpeg and served as optimized 960px/1080px WebP versions. It replaces the earlier inDrive and Leadway backgrounds. Its unique filename prevents reuse of an older cached image.

Other carousel WebP files are cleaned, enhanced derivatives of the supplied concept storyboard scenes, edited to remove baked-in UI following the user's instruction to use and improve those images. They are concept imagery; the Leadway scene is not authenticated campaign photography. Each slide uses its own background and separate HTML text/CTA/logo.

Source ZIP preserved at the project root. Reference videos are stored in `animations/` and are never loaded by the website carousel. Full provenance, links, animation details and validation limitations: `docs/HERO_CAROUSEL.md`.
